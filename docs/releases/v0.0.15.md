## ZaNytky 0.0.15 (пререліз)

П'ятнадцята тестова збірка: **читабельніші збіги й граф каналів**.

**Що нового**
- **Вкладка «Збіги»:** головний вид тепер рядки зі смугами по каналах (колір каналу, число дописів, логарифмічна шкала): видно, хто яке джерело, канал, сайт чи згадку використовує більше. Фільтр за видом із лічильниками, показ порціями («Показати ще»). Граф зв'язків відкривається на вимогу як запасний вид.
- **Графи каналів («Канали», «Збіги»):** без шкал надійності й форм, які стосуються лише тверджень; українські назви типів у легенді (канал, сайт, згадка, допис); більше підписів на вузлах; власна підказка замість «відкрити нотатку».
- Усе з попередніх версій: автопошук суб'єктів у текстах, хронологія з піками й розгортання вузлів, швидкий пошук, збіги без загальних платформ.

**Файли**
- `ZaNytky_0.0.15_Windows_x64_Portable.zip` - портативний архів (лише для ознайомлення).
- `ZaNytky_0.0.15_Setup_Windows_x64.exe`, `ZaNytky_0.0.15_Windows_x64.msi` - інсталятори.
- `ZaNytky_0.0.15_CLI_Windows_x64.zip` - командний рядок.
- `ZaNytky_0.0.15_macOS_arm64_Portable.zip`, `ZaNytky_0.0.15_macOS_x86_64_Portable.zip` - для Mac. Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Збіги - це підказки для гіпотез, а не докази.
- Тексти й файли джерел зберігаються без знеособлення, лише в локальній базі.
- Збірки **не підписані**; macOS-збірки не нотаризовані й не перевірялись на реальному Mac. Новий вигляд «Збігів» перевірено збіркою інтерфейсу в CI, у живому застосунку ще ні.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.

## ZaNytky 0.0.15 (pre-release)

Fifteenth test build: **more readable overlaps**. The "Overlaps" tab now shows rows with a bar per channel (channel colour, post count, logarithmic scale), a filter by kind and paging; the graph opens on demand. Channel graphs no longer show statement reliability scales, use readable type names and show more labels. Hints for hypotheses, not proofs. Builds are **unsigned**; macOS archives are untested on a real Mac. Checksums in `SHA256SUMS.txt`.
