## ZaNytky 0.0.25 (пререліз)

Двадцять п'ята тестова збірка: **командний рядок - пакет тверджень записується цілком або не записується**.

**Що нового**
- `zanytky make-statements --file ФАЙЛ.json`: перед першим записом тепер перевіряється весь файл - вид твердження, цитата, щонайменше дві сторони, роль кожної, існування суб'єкта. Раніше помилка в сторонах пізнього запису лишала в базі вже створені перші записи. Тепер повідомлення виглядає як «запис 2: потрібні щонайменше дві сторони (нічого не записано)».
- Перевірка сторін діє й з `--no-verify`; перевірка цитат лишилась як була.
- Застосунок, граф і документація без змін проти 0.0.24.

**Файли**
- `ZaNytky_0.0.25_Windows_x64_Portable.zip` - портативний архів (лише для ознайомлення).
- `ZaNytky_0.0.25_Setup_Windows_x64.exe`, `ZaNytky_0.0.25_Windows_x64.msi` - інсталятори.
- `ZaNytky_0.0.25_CLI_Windows_x64.zip` - командний рядок.
- `ZaNytky_0.0.25_macOS_arm64_Portable.zip`, `ZaNytky_0.0.25_macOS_x86_64_Portable.zip` - для Mac. Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Зміну перевірено автоматичними тестами (є тест на файл із пізнім хибним записом) і збіркою; на реальній базі ще не запускалась.
- Збірки **не підписані**; macOS-збірки не нотаризовані й не перевірялись на реальному Mac.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.

## ZaNytky 0.0.25 (pre-release)

Twenty-fifth test build: command line. `make-statements` now checks the whole batch file (kind, quote, at least two parties, roles, entities) before the first statement is written, so a late mistake no longer leaves half of the batch in the base. Nothing else changed since 0.0.24. Builds are **unsigned**; macOS archives are untested on a real Mac. Checksums in `SHA256SUMS.txt`.
