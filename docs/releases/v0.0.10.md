## ZaNytky 0.0.10 (пререліз)

Десята тестова збірка: **швидкий пошук джерел** і створення тверджень з джерела.

**Що нового**
- **Швидкий пошук у вкладці «Джерела»:** база веде повнотекстовий індекс (SQLite FTS5). Пошук за початками слів у назві, тексті й адресі, без різниці регістру («мінді» знаходить «Міндіча»); усі введені слова мають бути присутні. Сторінки беруться з бази, тексти всіх джерел у пам'ять не читаються, тож пошук лишається швидким і на великих базах з багатьох каналів. Індекс будується сам при першому відкритті бази (для вже імпортованих джерел) і далі оновлюється.
- **Створення суб'єкта і твердження з джерела** (форма під текстом джерела) і **зрозуміла помилка імпорту Telegram**, якщо в обраній папці немає `result.json` (з версій 0.0.8-0.0.9, якщо ви ще не оновлювались).
- Усередині архівів тека має ім'я з версією, наприклад `ZaNytky_0.0.10_Windows_x64_Portable`.

**Файли**
- `ZaNytky_0.0.10_Windows_x64_Portable.zip` - портативний архів (лише для ознайомлення).
- `ZaNytky_0.0.10_Setup_Windows_x64.exe`, `ZaNytky_0.0.10_Windows_x64.msi` - інсталятори.
- `ZaNytky_0.0.10_CLI_Windows_x64.zip` - командний рядок.
- `ZaNytky_0.0.10_macOS_arm64_Portable.zip`, `ZaNytky_0.0.10_macOS_x86_64_Portable.zip` - для Mac. Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Тексти й файли джерел зберігаються без знеособлення, лише в локальній базі; тримайте папку даних поза папками з кодом і робіть резервні копії.
- Збірки **не підписані**; macOS-збірки не нотаризовані й не перевірялись на реальному Mac.
- Швидкодію пошуку перевірено автоматичними тестами; на дуже великих обсягах (кілька каналів) ще не вимірювали. Імпорт каналу ще без індикатора прогресу.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.

## ZaNytky 0.0.10 (pre-release)

Tenth test build: **fast source search** (full-text index, SQLite FTS5; word beginnings, any letter case, pages read from the database, so it stays fast on large databases with many channels) plus making statements from a source and a clear error when a Telegram export folder has no `result.json`. Builds are **unsigned**; macOS archives are untested on a real Mac; search speed on very large data has not been measured yet. Checksums in `SHA256SUMS.txt`.
