## ZaNytky 0.0.17 (пререліз)

Сімнадцята тестова збірка: **швидкий «Огляд бази»**.

**Що нового**
- Виправлено швидкодію «Огляду» (вкладка «Огляд», `zanytky overview`): раніше на великій базі (десятки тисяч джерел) звіт складався дуже довго, бо для кожного знайденого імені перевірялось, чи відоме воно в базі. Тепер така перевірка робиться лише для відібраних кандидатів (найпоширеніших), тож огляд складається за помірний час.
- Усе з попередніх версій: «Огляд» з імовірними зв'язками, «Канали» (хронологія з піками, розгортання вузлів), «Збіги» (рядки зі смугами по каналах), автопошук суб'єктів, швидкий пошук, перегляд фото в картці джерела.

**Файли**
- `ZaNytky_0.0.17_Windows_x64_Portable.zip` - портативний архів (лише для ознайомлення).
- `ZaNytky_0.0.17_Setup_Windows_x64.exe`, `ZaNytky_0.0.17_Windows_x64.msi` - інсталятори.
- `ZaNytky_0.0.17_CLI_Windows_x64.zip` - командний рядок.
- `ZaNytky_0.0.17_macOS_arm64_Portable.zip`, `ZaNytky_0.0.17_macOS_x86_64_Portable.zip` - для Mac. Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Огляд і зв'язки - це підказки для гіпотез, не факти й не висновки.
- Тексти й файли джерел зберігаються без знеособлення, лише в локальній базі.
- Збірки **не підписані**; macOS-збірки не нотаризовані й не перевірялись на реальному Mac. Час складання огляду на реальній базі після виправлення ще не виміряно.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.

## ZaNytky 0.0.17 (pre-release)

Seventeenth test build: the **Overview** is fast again. It used to check, for every name found, whether the base already knows it, which took very long on a large base; now the check is made only for the selected (most widespread) candidates. Hints for hypotheses, not facts. Builds are **unsigned**; macOS archives are untested on a real Mac; the time of the overview on the real base has not been measured yet. Checksums in `SHA256SUMS.txt`.
