## ZaNytky 0.0.5 (пререліз)

П'ята тестова збірка для Windows і macOS. Головне: **усі пакети для Windows — і портативний архів, і інсталятори — не потребують нічого встановлювати в системі** (вбудоване середовище вікна WebView2).

**Що нового**
- Інсталятори `.msi/.exe` містять власне середовище вікна, як і портативний архів. Перевірено в збірці: після тихого встановлення програма працює зі своїм середовищем.
- Резервна копія папки даних: один зашифрований файл (системний ключ, список ключів розслідувачів, бази). Кнопки «Зробити копію…» / «Відновити з копії…» на вкладці «Налаштування» і команди `zanytky backup` / `zanytky restore`. Відновлення працює лише в порожню папку й нічого не перезаписує. Приватний ключ розслідувача в копію не входить.
- «Розбір документа» відкриває файли Word (`.docx`): текст береться з абзаців і таблиць.
- Розділи можна відкривати в окремих вікнах (кнопка ⧉).
- Автоматичні перевірки: тест паритету 7 мов інтерфейсу, перевірка єдиної версії, збірка оболонки застосунку в кожному запиті на злиття.

**Файли**
- `ZaNytky_0.0.5_Windows_x64_Portable.zip` — без встановлення.
- `ZaNytky_0.0.5_Setup_Windows_x64.exe`, `ZaNytky_0.0.5_Windows_x64.msi` — інсталятори (великі, бо містять середовище вікна).
- `ZaNytky_0.0.5_CLI_Windows_x64.zip` — командний рядок.
- `ZaNytky_0.0.5_macOS_arm64_Portable.zip`, `ZaNytky_0.0.5_macOS_x86_64_Portable.zip` — для Mac (системне вікно macOS, нічого ставити не потрібно). Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` — контрольні суми.

**Важливо**
- Збірки **не підписані**; macOS-збірки не нотаризовані й **не перевірялись на реальному Mac** (див. README.txt в архіві).
- Імпорту PDF поки немає (скопіюйте текст вручну або збережіть файл як `.docx`).
- Ранній тестовий випуск. Тримайте папку даних **поза** папками з програмним кодом і робіть резервні копії; системний ключ, приватний ключ розслідувача й парольну фразу зберігайте окремо.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон — українська.

## ZaNytky 0.0.5 (pre-release)

Fifth test build. **All Windows packages, portable and installers, need nothing installed in the system** (the web view runtime is included). New: encrypted backup and restore of the data folder (buttons and `zanytky backup`/`restore`), reading Word (`.docx`) files in "Document analysis", sections in separate windows, automatic checks (language parity, single version, app shell build). No PDF import yet. macOS archives are included if their build succeeded; unsigned, not notarized and untested on a real Mac. Builds are **unsigned**; early test version. Checksums in `SHA256SUMS.txt`.
