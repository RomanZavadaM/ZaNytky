## ZaNytky 0.0.4 (пререліз)

Четверта тестова збірка. Головне: портативний архів для Windows **не потребує нічого встановлювати**.

**Що нового**
- Портативний архів містить власне середовище вікна (папка `webview2` поруч із `ZaNytky.exe`); системний Microsoft Edge WebView2 не потрібен. Не відокремлюйте цю папку від програми.
- Розділи можна відкривати в окремих вікнах (кнопка ⧉ у шапці): наприклад, «Базу» поруч із «Розбором документа». Налаштування спільні, база оновлюється в усіх вікнах після імпорту; закриття вікна з незбереженим текстом - із запитом.
- Збірки для macOS (Apple silicon і Intel) у вигляді портативних архівів (див. нижче).

**Файли**
- `ZaNytky_0.0.4_Windows_x64_Portable.zip` - застосунок без встановлення (великий, бо містить середовище вікна).
- `ZaNytky_0.0.4_Setup_Windows_x64.exe` і `ZaNytky_0.0.4_Windows_x64.msi` - інсталятори (**поки користуються системним WebView2**).
- `ZaNytky_0.0.4_CLI_Windows_x64.zip` - командний рядок (`zanytky.exe help`).
- `ZaNytky_0.0.4_macOS_arm64_Portable.zip`, `ZaNytky_0.0.4_macOS_x86_64_Portable.zip` - застосунок і командний рядок для Mac (системне вікно macOS, нічого ставити не потрібно). Якщо цих файлів немає в списку, macOS-збірка не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Збірки **не підписані**; macOS-збірки не нотаризовані й **не перевірялись на реальному Mac**: перший запуск через «Відкрити» в контекстному меню (див. README.txt в архіві).
- Ранній тестовий випуск. Тримайте папку даних **поза** папками з програмним кодом; системний ключ, приватний ключ розслідувача й парольну фразу зберігайте окремо.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.

## ZaNytky 0.0.4 (pre-release)

Fourth test build. The Windows portable archive **needs nothing to be installed**: it ships its own web view runtime (`webview2` folder next to `ZaNytky.exe`; keep it with the program). Sections can be opened in separate windows (⧉ button). macOS portable archives (Apple silicon and Intel) are included if their build succeeded; they are unsigned, not notarized and untested on a real Mac. The .msi/.exe installers still use the system WebView2. Builds are **unsigned**; early test version. Checksums in `SHA256SUMS.txt`.
