## ZaNytky 0.0.20 (пререліз)

Двадцята тестова збірка: **розширений командний рядок** для автоматичного розбору документів і каналів.

**Що нового (командний рядок `zanytky`)**
- Читання (усі з `--json`): `search ЗАПИТ` (пошук по джерелах), `source НОМЕР [--full]`, `discover --source N | --all` (суб'єкти в тексті з позначкою «є в базі»), `channels [--channel N]`, `overlaps`, `pairs`, `entity НОМЕР`, `statements [--grep]`.
- Запис: `add-entity`, `add-source` (сторінка чи документ як джерело з текстом), `make-statements --file ФАЙЛ.json` (твердження пакетом; **цитата кожного має бути дослівно в тексті свого джерела, інакше нічого не записується**), `evidence` (докази до твердження; підтвердити можна лише видом «реєстр» чи «заява органу»).
- Застосунок без змін відносно 0.0.19.

**Файли**
- `ZaNytky_0.0.20_Windows_x64_Portable.zip` - портативний архів (лише для ознайомлення).
- `ZaNytky_0.0.20_Setup_Windows_x64.exe`, `ZaNytky_0.0.20_Windows_x64.msi` - інсталятори.
- `ZaNytky_0.0.20_CLI_Windows_x64.zip` - командний рядок.
- `ZaNytky_0.0.20_macOS_arm64_Portable.zip`, `ZaNytky_0.0.20_macOS_x86_64_Portable.zip` - для Mac. Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Огляд, збіги й автопошук - підказки для гіпотез, не факти; «підтверджено» лише за документом реєстру чи органу.
- Збірки **не підписані**; macOS-збірки не нотаризовані й не перевірялись на реальному Mac.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.

## ZaNytky 0.0.20 (pre-release)

Twentieth test build: an extended **command line** for automated analysis of documents and channels (search, source, discover, channels, overlaps, pairs, entity, statements with `--json`; add-entity, add-source, make-statements with verbatim quote checking, evidence). The app is unchanged from 0.0.19. Hints for hypotheses, not facts. Builds are **unsigned**; macOS archives are untested on a real Mac. Checksums in `SHA256SUMS.txt`.
