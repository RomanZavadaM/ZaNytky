## ZaNytky 0.0.22 (пререліз)

Двадцять друга тестова збірка: **граф** (автономний HTML-файл, виправлення розгорнутого вікна й лічильника).

**Що нового**
- **Граф у застосунку.** «Розгорнути» більше не дає порожнє полотно: воно має мінімальну висоту й перемальовується при зміні розміру. Лічильник «Зв'язків» рахує реальні лінії (зв'язки з тверджень), а не лише прості посилання.
- **Збереження графа як HTML** (вкладка «Граф»): весь граф або лише навколо суб'єкта № (1-3 кроки), за потреби лише підтверджені. Файл автономний: без інтернету, з пошуком, кліком по вузлу й лінії. Імена осіб видно, якщо ввімкнено «Показувати імена осіб».
- **Командний рядок:** `graph --out ФАЙЛ.html [--entity N --depth K] [--grep ТЕКСТ] [--confirmed] [--identity ФАЙЛ]`. Існуючий файл не перезаписується.

**Файли**
- `ZaNytky_0.0.22_Windows_x64_Portable.zip` - портативний архів (лише для ознайомлення).
- `ZaNytky_0.0.22_Setup_Windows_x64.exe`, `ZaNytky_0.0.22_Windows_x64.msi` - інсталятори.
- `ZaNytky_0.0.22_CLI_Windows_x64.zip` - командний рядок.
- `ZaNytky_0.0.22_macOS_arm64_Portable.zip`, `ZaNytky_0.0.22_macOS_x86_64_Portable.zip` - для Mac. Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Виправлення розгорнутого графа й кнопку збереження перевірено автоматичними тестами й збіркою, у живому застосунку ще ні.
- Збірки **не підписані**; macOS-збірки не нотаризовані й не перевірялись на реальному Mac.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.
