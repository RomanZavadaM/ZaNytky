## ZaNytky 0.0.14 (пререліз)

Чотирнадцята тестова збірка: **чистіші збіги між каналами**.

**Що нового**
- У вкладці «Збіги» більше не показуються загальні платформи, на які посилається кожен канал (YouTube, Facebook, Instagram, X/Twitter, скорочувачі посилань, monobank, telegra.ph та подібні). Зверху лишаються специфічні збіги: спільні джерела пересилань, спільні канали, сайти, згадки, однакові тексти й прямі зв'язки між каналами.
- Усе з попередніх версій: вкладка «Канали» (хронологія з піками, розгортання вузлів), автопошук суб'єктів у текстах, швидкий пошук.

**Файли**
- `ZaNytky_0.0.14_Windows_x64_Portable.zip` - портативний архів (лише для ознайомлення).
- `ZaNytky_0.0.14_Setup_Windows_x64.exe`, `ZaNytky_0.0.14_Windows_x64.msi` - інсталятори.
- `ZaNytky_0.0.14_CLI_Windows_x64.zip` - командний рядок.
- `ZaNytky_0.0.14_macOS_arm64_Portable.zip`, `ZaNytky_0.0.14_macOS_x86_64_Portable.zip` - для Mac. Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Збіги - це підказки для гіпотез, а не докази.
- Тексти й файли джерел зберігаються без знеособлення, лише в локальній базі.
- Збірки **не підписані**; macOS-збірки не нотаризовані й не перевірялись на реальному Mac.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.
