## ZaNytky 0.0.9 (пререліз)

Дев'ята тестова збірка: виправлення й зручність.

**Що нового**
- **Імена з версією всередині архівів:** папка, що з'являється після розпаковування, тепер називається разом з версією (наприклад `ZaNytky_0.0.9_Windows_x64_Portable`), тож нова версія не переписує попередню в тій самій теці. Це стосується портативного архіву Windows, командного рядка й macOS-архівів.
- **Зрозуміла помилка імпорту Telegram:** якщо в обраній папці немає `result.json`, програма просить обрати саму папку експорту Telegram Desktop (JSON), де лежить `result.json`.
- README на GitHub: завантаження нагорі (таблиця прямих посилань).

**Файли**
- `ZaNytky_0.0.9_Windows_x64_Portable.zip` - портативний архів (лише для ознайомлення).
- `ZaNytky_0.0.9_Setup_Windows_x64.exe`, `ZaNytky_0.0.9_Windows_x64.msi` - інсталятори.
- `ZaNytky_0.0.9_CLI_Windows_x64.zip` - командний рядок.
- `ZaNytky_0.0.9_macOS_arm64_Portable.zip`, `ZaNytky_0.0.9_macOS_x86_64_Portable.zip` - для Mac. Якщо цих файлів немає, збірка macOS не вдалася.
- `SHA256SUMS.txt` - контрольні суми.

**Важливо**
- Тексти й файли джерел зберігаються без знеособлення, лише в локальній базі; тримайте папку даних поза папками з кодом і робіть резервні копії.
- Збірки **не підписані**; macOS-збірки не нотаризовані й **не перевірялись на реальному Mac**.
- Переклади FR/DE/ES/KO/JA машинні й не вичитані носіями мов; еталон - українська.

## ZaNytky 0.0.9 (pre-release)

Ninth test build: fixes and convenience. The folder inside every archive now carries the version (for example `ZaNytky_0.0.9_Windows_x64_Portable`), so a new version does not overwrite the previous one. A clear error when the chosen Telegram export folder has no `result.json`. Builds are **unsigned**; macOS archives are untested on a real Mac. Checksums in `SHA256SUMS.txt`.
