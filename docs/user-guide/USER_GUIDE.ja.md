# ZaNytky - ユーザーガイド

[🇺🇦 Українська](USER_GUIDE.uk.md) · [🇬🇧 English](USER_GUIDE.en.md) · [🇫🇷 Français](USER_GUIDE.fr.md) · [🇩🇪 Deutsch](USER_GUIDE.de.md) · [🇪🇸 Español](USER_GUIDE.es.md) · [🇰🇷 한국어](USER_GUIDE.ko.md) · **🇯🇵 日本語**

このガイドはアプリケーションのウィンドウを説明します。基準はウクライナ語版です。

> この翻訳は自動生成であり、ネイティブによる校閲を受けていません。基準はウクライナ語の文面です。

## 1. 設定

- **データフォルダー**（空が望ましい）を選び、「フォルダーを準備」を押します。システム鍵 `system.key` と調査員の公開鍵を記した `recipients.txt` が作られます。
- **調査員の鍵**を作成します。アプリケーションが選んだファイルに秘密鍵を書き込み、公開鍵を `recipients.txt` に追加します。秘密鍵は氏名の開示とレポートに必要で、なければデータを開示できません。ファイルは安全な場所に保管し、コピーも作ってください。

## 2. 文書の準備

- タイトル、情報源の種類（報道、登記簿、当局の発表、証言、噂、自前）、任意でアドレス、パッケージ ID（文書ごとに一意）を入力します。
- テキストを貼り付けるかファイルを開きます。必要なら**調査員の文脈**を追加します（例:「イワノフ I. は例示有限会社の代表」）。
- 「匿名化して AI 用パッケージを作成」を押します。既知の氏名、納税番号、電話、メールが仮名に置き換えられます。匿名化されたテキストと指示をコピーして AI に渡します。
- 「システムが認識できなかった言及」で各言及について、**同じ人物**（仮名を入力）、**新しい人物**（氏名、任意で納税番号・電話・メール）、**人物ではない**のいずれかを選びます。その後、パッケージを再作成します。

## 3. AI の結果

- AI の回答（result.json ファイル）とパッケージ ID を貼り付け、「検査」を押します。構造とルールが検査され、引用付きの確認内容が表示されます。確認後にのみ「データベースにインポート」を押してください。
- すべて「未検証」としてインポートされます。パッケージは一度だけインポートできます。

## 4. データベース

- 評価（例: B3 = 情報源の信頼度 B、信憑性 3）と状態を持つ記述の一覧です。人物は仮名でのみ表示されます。
- 「確認」は、噂でも証言でもない情報源がある場合にのみ可能で、そうでなければ拒否されます。「反証」は記述を反証済みにします（削除はされません）。

## 5. レポート

- 形式（Word、PDF、Markdown）を選び、パスフレーズを入力します。レポートは秘密鍵で人物を開示するため、個人情報がそのまま含まれます。パスフレーズなしでは、「パスフレーズなし」を明示的に確認した場合にのみ作成されます。
- 保護されたレポートの拡張子は `.age` で、[age](https://age-encryption.org) とパスフレーズで開きます。

## セキュリティ

- システム鍵、調査員の秘密鍵、パスフレーズは別々に保管してください。秘密鍵を失うとデータを開示できなくなります。
- アプリケーションはネットワークに何も送信しません。AI に渡すテキストはコンピューターの外に出るため、公開情報源の資料のみを使用してください。

## よくある質問

- Windows が不明な発行元を警告する: ビルドは署名されていません。「詳細情報」→「実行」を選んでください。
- 空のウィンドウや起動エラー: Microsoft Edge WebView2 が必要です（Windows 10/11 にあります）。

## 試用シナリオ（架空のデータ）

1. 「設定」タブ: 空のフォルダーを選び、「フォルダーを準備」を押して調査員の鍵を作成します。
2. 「文書の準備」タブ: `docs/examples/sample-document.md` のテキストを貼り付け、タイトル「試用文書」、パッケージ ID `pkg-1` で「匿名化してパッケージを作成」を押します。
3. 認識されなかった言及の一覧で「Петро Іваненко」に「新しい人物」を選び、氏名、納税番号 1234567890、電話 +38 050 123 45 67 を入力して「適用」を押します。パッケージを再作成すると、氏名・納税番号・電話が一つの仮名に置き換わります。
4. 指示と匿名化されたテキストを AI のチャットにコピーし、JSON のみで回答するよう依頼します。回答を保存します。
5. 「AI の結果」タブ: 回答を貼り付けて「検査」を押し、確認内容を読んで「データベースにインポート」を押します。
6. 「データベース」タブ: 記述を閲覧し、「確認」を試します（噂を情報源とする記述はアプリケーションが拒否します）。
7. 「レポート」タブ: パスフレーズ付きの Word レポートを作成し、age で開いて実名が含まれていることを確認します。
