このガイドはアプリケーションのウィンドウを説明します。基準はウクライナ語版です。

> この翻訳は自動生成であり、ネイティブによる校閲を受けていません。基準はウクライナ語の文面です。

## 1. 設定

- **データフォルダー**（空が望ましい）を選び、「フォルダーを準備」を押します。システム鍵 `system.key` と調査員の公開鍵を記した `recipients.txt` が作られます。
- **調査員の鍵**を作成します。アプリケーションが選んだファイルに秘密鍵を書き込み、公開鍵を `recipients.txt` に追加します。秘密鍵は氏名の開示とレポートに必要で、なければデータを開示できません。ファイルは安全な場所に保管し、コピーも作ってください。

## 2. 文書の準備

- タイトル、情報源の種類（報道、登記簿、当局の発表、証言、噂、自前）、任意でアドレス、パッケージ ID（文書ごとに一意）を入力します。
- テキストを貼り付けるかファイルを開きます。必要なら**調査員の文脈**を追加します（例:「イワノフ I. は例示有限会社の代表」）。
- 「匿名化して AI 用パッケージを作成」を押します。既知の氏名、納税番号、電話、メールが仮名に置き換えられます。匿名化されたテキストと指示をコピーして AI に渡します。
- 「システムが認識できなかった言及」で各言及について、**同じ人物**（仮名を入力）、**新しい人物**（氏名、任意で納税番号・電話・メール）、**人物ではない**のいずれかを選びます。その後、パッケージを再作成します。

## 3. AI の結果

- AI の回答（result.json ファイル）とパッケージ ID を貼り付け、「検査」を押します。構造とルールが検査され、引用付きの確認内容が表示されます。確認後にのみ「データベースにインポート」を押してください。
- すべて「未検証」としてインポートされます。パッケージは一度だけインポートできます。

## 4. データベース

- 評価（例: B3 = 情報源の信頼度 B、信憑性 3）と状態を持つ記述の一覧です。人物は仮名でのみ表示されます。
- 「確認」は、噂でも証言でもない情報源がある場合にのみ可能で、そうでなければ拒否されます。「反証」は記述を反証済みにします（削除はされません）。

## 5. レポート

- 形式（Word、PDF、Markdown）を選び、パスフレーズを入力します。レポートは秘密鍵で人物を開示するため、個人情報がそのまま含まれます。パスフレーズなしでは、「パスフレーズなし」を明示的に確認した場合にのみ作成されます。
- 保護されたレポートの拡張子は `.age` で、[age](https://age-encryption.org) とパスフレーズで開きます。

## 6. 情報源と Telegram チャンネル

- **チャンネルの取り込み。** Telegram Desktop：チャンネル →「チャット履歴をエクスポート」→ JSON 形式。「情報源」タブで「フォルダーを選んで取り込む」を押し、`result.json` のあるフォルダーを選びます。各投稿が全文付きの情報源になり、写真・動画・ファイルは添付になります。取り込みは繰り返せ、重複しません。情報源の信頼度の既定値は F（不明）です。
- **情報源。** タイトル・本文・アドレスで検索します（単語の先頭、大文字小文字を区別しない、すべての単語が必要）。開いた情報源では：本文（貼り付け・保存・コピー）、「ファイルを追加」、「フォルダーで表示」、「画像を表示」。
- **情報源から主張を作る。** 種類、値、信頼性 1-6、**必須の引用**、役割を持つ当事者 2-4 件（既存または新規の対象）。新しい人物はフルネームで入力します。名前は封印された登録簿に入り、データベースには仮名だけが残ります。主張は常に「未検証」です。
- **対象の自動検出。** 「テキストから対象を探す」は人物、組織（有限会社「…」）、登録コードを「データベースにあり」または「新規」と示し、「データベースに追加」ボタンを出します。「全テキストの新しい対象」は未知の対象の上位を示します。ヒントなので手で確認してください。
- **チャンネル。** 月ごとの時系列と活動のピーク、エクスポートにない投稿番号（削除された可能性）、チャンネルのグラフ：どこから転送するか、何にリンクするか、誰に言及するか。ノードをクリックすると展開します。以前に取り込んだチャンネルの分析を埋めるには、そのフォルダーをもう一度取り込みます。
- **重なり**（チャンネル 2 つ以上）：チャンネルごとの棒がある行 - 共通の転送元、チャンネル、サイト、言及、長い同一テキスト。種類で絞り込み、グラフは要求時に表示。一般的なプラットフォーム（YouTube、Facebook など）は除外されます。
- **概要。** ボタン 1 つでデータベース全体のレポートを作ります：チャンネル、ピーク、重なり、新しい対象、**ありそうなつながり**（同じ段落で 3 件以上の投稿に言及された対象の組、引用例付き）。`.md` として保存できます。コマンドラインでは `zanytky overview --home フォルダー --out ファイル`。
- **重要。** 重なり、ピーク、自動検出、概要は仮説のためのヒントであり、事実ではありません。本文とファイルは匿名化せずローカルのデータベースにのみ保存されます。データフォルダーはコードフォルダーの外に置き、バックアップを取ってください。

## 7. 証拠、グラフ、コマンドライン

- **証拠を追加。**主体カードの主張の横：文書の種類（登記、機関の声明、メディア、証言、自前）、信頼度 A-F、題名、アドレス、日付、本文または抜粋、メモ。「追加して確認」は「登記」と「機関の声明」のみ、「追加して反証」はどの種類でも使えます。同じアドレスは重複しません。
- **グラフ。**「グラフ」タブ：線の色は関係の種類（所有、役職、報じられた関係など）、太い実線は文書で確認済み、破線はまだ未確認です。ノードにはラベルが付き、調査者の鍵を指定すると人物名が表示されます。「グラフを HTML で保存...」は単独のファイル（インターネット不要、検索付き）を書き出します。全体、または主体番号の周辺のみ（1〜3 ステップ）、必要なら確認済みのみ。
- **分析用コマンドライン。**`search 検索語`、`source 番号 --full`、`discover --source N`、`channels`、`overlaps`、`pairs`、`entity N`、`statements --grep`、`add-source`、`add-entity`、`make-statements --file ファイル.json`（各主張の引用は情報源の本文に一字一句あること。そうでなければ何も書き込まれません）、`evidence`、`graph --out ファイル.html [--entity N --depth K] [--confirmed]`。読み取り系コマンドはすべて `--json` に対応します。
- **誤りの修正。**`detach --statement N --source M [--drop-source]` は誤って追加した証拠を外します。`delete-statement N` と `delete-source N` は誤った主張や未使用の情報源を削除します。`merge --keep A --drop B` は重複（人物を除く）を統合し、`unmerge --drop B` で戻せます。`evidence --expect 語句` は誤った番号への書き込みを防ぎます。削除は元に戻せない（記録されます）ので、先に `backup` してください。

## セキュリティ

- システム鍵、調査員の秘密鍵、パスフレーズは別々に保管してください。秘密鍵を失うとデータを開示できなくなります。
- アプリケーションはネットワークに何も送信しません。AI に渡すテキストはコンピューターの外に出るため、公開情報源の資料のみを使用してください。

## よくある質問

- Windows が不明な発行元を警告する: ビルドは署名されていません。「詳細情報」→「実行」を選んでください。
- 空のウィンドウや起動エラー: `webview2` フォルダーが `ZaNytky.exe` の隣にあるか確認してください（ポータブル版とインストーラーのどちらにも WebView2 が含まれています）。

## 試用シナリオ（架空のデータ）

1. 「設定」タブ: 空のフォルダーを選び、「フォルダーを準備」を押して調査員の鍵を作成します。
2. 「文書の準備」タブ: `docs/examples/sample-document.md` のテキストを貼り付け、タイトル「試用文書」、パッケージ ID `pkg-1` で「匿名化してパッケージを作成」を押します。
3. 認識されなかった言及の一覧で「Петро Іваненко」に「新しい人物」を選び、氏名、納税番号 1234567890、電話 +38 050 123 45 67 を入力して「適用」を押します。パッケージを再作成すると、氏名・納税番号・電話が一つの仮名に置き換わります。
4. 指示と匿名化されたテキストを AI のチャットにコピーし、JSON のみで回答するよう依頼します。回答を保存します。
5. 「AI の結果」タブ: 回答を貼り付けて「検査」を押し、確認内容を読んで「データベースにインポート」を押します。
6. 「データベース」タブ: 記述を閲覧し、「確認」を試します（噂を情報源とする記述はアプリケーションが拒否します）。
7. 「レポート」タブ: パスフレーズ付きの Word レポートを作成し、age で開いて実名が含まれていることを確認します。
