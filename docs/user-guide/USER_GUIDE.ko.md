# ZaNytky - 사용자 가이드

[🇺🇦 Українська](USER_GUIDE.uk.md) · [🇬🇧 English](USER_GUIDE.en.md) · [🇫🇷 Français](USER_GUIDE.fr.md) · [🇩🇪 Deutsch](USER_GUIDE.de.md) · [🇪🇸 Español](USER_GUIDE.es.md) · **🇰🇷 한국어** · [🇯🇵 日本語](USER_GUIDE.ja.md)

이 가이드는 애플리케이션 창을 설명합니다. 기준 텍스트는 우크라이나어 버전입니다.

> 이 번역은 자동 생성되었으며 원어민 검수를 거치지 않았습니다. 기준 텍스트는 우크라이나어입니다.

## 1. 설정

- **데이터 폴더**(비어 있는 것이 좋음)를 선택하고 "폴더 준비"를 누릅니다. 폴더에 시스템 키 `system.key`와 조사관 공개 키가 담긴 `recipients.txt`가 생깁니다.
- **조사관 키**를 만듭니다. 애플리케이션이 선택한 파일에 개인 키를 쓰고 공개 키를 `recipients.txt`에 추가합니다. 개인 키는 이름을 공개하고 보고서를 만들 때 필요하며, 없으면 데이터를 공개할 수 없습니다. 파일을 안전한 곳에 보관하고 사본을 만드세요.

## 2. 문서 준비

- 제목, 출처 종류(언론, 등록부, 기관 발표, 증언, 소문, 자체), 선택적으로 주소, 패키지 ID(문서마다 고유)를 입력합니다.
- 텍스트를 붙여넣거나 파일을 엽니다. 필요하면 **조사관의 맥락**을 추가합니다(예: "이바노프 I.는 예시 유한회사의 대표").
- "비식별화하고 AI용 패키지 만들기"를 누릅니다. 애플리케이션이 알려진 이름, 세금 번호, 전화, 이메일을 가명으로 바꿉니다. 비식별화된 텍스트와 지침을 복사해 AI에 전달하세요.
- "시스템이 인식하지 못한 언급"에서 각 언급마다 **같은 사람**(가명 입력), **새 사람**(전체 이름, 선택적으로 세금 번호·전화·이메일), **사람이 아님** 중 하나를 고릅니다. 그런 다음 패키지를 다시 만드세요.

## 3. AI 결과

- AI의 답변(result.json 파일)과 패키지 ID를 붙여넣고 "검사"를 누릅니다. 애플리케이션이 구조와 규칙을 검사하고 인용이 포함된 검토 내용을 보여줍니다. 검토 후에만 "데이터베이스로 가져오기"를 누르세요.
- 모든 것은 "미검증"으로 가져옵니다. 패키지는 한 번만 가져올 수 있습니다.

## 4. 데이터베이스

- 등급(예: B3 = 출처 신뢰도 B, 신빙성 3)과 상태가 있는 진술 목록입니다. 사람은 가명으로만 표시됩니다.
- "확인"은 소문이나 증언이 아닌 출처가 있을 때만 가능하며, 아니면 애플리케이션이 거부합니다. "반박"은 진술을 반박됨으로 표시합니다(삭제되지 않음).

## 5. 보고서

- 형식(Word, PDF, Markdown)을 선택하고 암호문을 입력합니다. 보고서는 개인 키로 사람을 공개하므로 개인정보가 그대로 들어 있습니다. 암호문 없이는 "암호문 없음"을 명시적으로 확인해야만 만들 수 있습니다.
- 보호된 보고서의 확장자는 `.age`이며 [age](https://age-encryption.org)와 암호문으로 엽니다.

## 보안

- 시스템 키, 조사관의 개인 키, 암호문은 따로 보관하세요. 개인 키를 잃으면 데이터를 더는 공개할 수 없습니다.
- 애플리케이션은 네트워크로 아무것도 보내지 않습니다. AI에 넘기는 텍스트는 컴퓨터를 떠나므로 공개 출처 자료만 사용하세요.

## 자주 묻는 질문

- Windows가 알 수 없는 게시자를 경고함: 빌드가 서명되지 않았습니다. "추가 정보" 후 "실행"을 선택하세요.
- 빈 창이나 시작 오류: `webview2` 폴더가 `ZaNytky.exe` 옆에 있는지 확인하세요(휴대용 압축 파일과 설치 프로그램 모두 WebView2를 포함합니다).

## 시험 시나리오(가상 데이터)

1. "설정" 탭: 빈 폴더를 선택하고 "폴더 준비"를 누른 뒤 조사관 키를 만듭니다.
2. "문서 준비" 탭: `docs/examples/sample-document.md`의 텍스트를 붙여넣고, 제목 "시험 문서", 패키지 ID `pkg-1`로 "비식별화하고 패키지 만들기"를 누릅니다.
3. 인식되지 않은 언급 목록에서 "Петро Іваненко"에 "새 사람"을 선택하고 전체 이름, 세금 번호 1234567890, 전화 +38 050 123 45 67을 입력한 뒤 "적용"을 누릅니다. 패키지를 다시 만들면 이름, 세금 번호, 전화가 하나의 가명으로 바뀝니다.
4. 지침과 비식별화된 텍스트를 AI 채팅에 복사하고 JSON으로만 답하도록 요청합니다. 답변을 저장합니다.
5. "AI 결과" 탭: 답변을 붙여넣고 "검사"를 누른 뒤 검토 내용을 읽고 "데이터베이스로 가져오기"를 누릅니다.
6. "데이터베이스" 탭: 진술을 보고 "확인"을 시도합니다(소문이 출처인 진술은 애플리케이션이 거부합니다).
7. "보고서" 탭: 암호문으로 Word 보고서를 만들고 age로 열어 실제 이름이 들어 있는지 확인합니다.
