# ZaNytky («За нитку»)

Застосунок для впорядкування зв'язків між суб'єктами з відкритих джерел із псевдонімізацією персональних даних за ключем.

Статус: **ранній етап розробки**, готових збірок немає. Мова реалізації - Rust. Українська - основна мова інтерфейсу й документації.
